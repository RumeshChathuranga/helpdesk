# Screenshots

Drop PNGs here with these exact filenames and they'll show up in the root `README.md`
automatically (no other edits needed):

| Filename | Suggested shot |
| --- | --- |
| `dashboard.png` | Dashboard page — status/category breakdown, recent tickets |
| `tickets-list.png` | Ticket list — a few tickets visible, a filter or sort applied |
| `ticket-detail.png` | Ticket detail page with an AI draft reply showing the "Awaiting approval" badge |
| `knowledge-base.png` | Knowledge base admin page — a document mid-processing or ready, with passage count |
| `grafana-dashboard.png` (optional) | The Grafana dashboard from the Helm chart, if you've deployed the observability stack |

A width around 1400px, PNG or WEBP, is plenty — GitHub scales them down in the README.
