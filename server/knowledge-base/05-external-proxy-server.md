# External web proxy for off-campus access to subscribed resources

> Source: https://uom.lk/cites/support/external-proxy-server
> Retrieved: 2026-07-30 · Status: SOURCED (extracted from the live CITeS page — treat the URL as authoritative for anything not covered here)

### Q: How do I access UoM-subscribed journals and databases from off campus?

The external proxy lets you reach University of Moratuwa's subscribed educational repositories from outside the campus network.

1. Open your browser's proxy settings.
2. Enter `cache2.uom.lk` as the HTTP proxy address and `3128` as the port number, then save.
3. When prompted, authenticate with your UoM credentials.

### Q: What are the rules for using the external proxy?

- It works only from outside the university network — on campus, use the campus network directly.
- It is for educational purposes only.
- It provides access solely to UoM-subscribed external educational repositories, not general web browsing.
- Misuse results in a permanent service ban and account deactivation without notice.
