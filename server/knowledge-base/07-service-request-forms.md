# Downloadable service request forms

> Source: https://uom.lk/cites/Support/Download-Service-request-forms
> Retrieved: 2026-07-30 · Status: SOURCED (extracted from the live CITeS page — treat the URL as authoritative for anything not covered here)

### Q: How do I request a new UoM account?

Download the **UOM Account Request Form** from the CITeS service request forms page. Note: the requester must be present in person during account creation, for security purposes.

### Q: How do I request a virtual server?

Download the **Virtual Server Request Form** (`UoM-Virtual-Server-request-form-for-Projects`). Complete it, scan it, and submit it as a ticket through the UoM IT Help Desk under **Specialized Services / Virtual Server / Requests**.

### Q: How do I report an IP phone problem?

There is no separate form to download. Go to the UoM IT Help Desk and create a ticket under **Core Services / Network / IP Phone Issues**.
