# Add an identity and signature to your UoM mail account

> Source: https://uom.lk/cites/support/UOM_mail_identity%26signature
> Retrieved: 2026-07-30 · Status: SOURCED (extracted from the live CITeS page — treat the URL as authoritative for anything not covered here)

### Q: How do I set up an email signature on UoM WebMail?

1. Login to UoM mail via `web.mail.uom.lk`. Go to **Settings** from the user menu in the top right corner.
2. Open the **Settings** panel from that same user menu.
3. Select the **Identities** option from the available settings.
4. Enter the name you want to display as your sender identity.
5. Tick the checkbox to add a signature.
6. Compose your signature text in the provided field.
7. Click **Update** to save the changes.
8. Compose a new message to confirm your identity and signature appear automatically.
